# Windward public pages

Static support and privacy pages for the standalone Apple Watch barometer by Alexey Shtol.

Only public website files live in this repository. No application source, credentials or API keys are included.

## GitHub Pages

Publish from branch `main`, folder `/(root)` in Settings → Pages. No build tools, tracking scripts, cookies, external font requests or dependencies are required.

- Support: https://alexxf73.github.io/windward-site/support/
- Privacy: https://alexxf73.github.io/windward-site/privacy/
